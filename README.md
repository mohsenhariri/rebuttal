# OpenReview Rebuttal Editor

Side-by-side editor for drafting OpenReview rebuttals.

Online: https://mohsenhariri.github.io/rebuttal

## Features

- OpenReview-style Markdown preview
- `MathJax` OpenReview's TeX configuration
- Local autosave
- Named checkpoints
- [ ] Diff Checker

Run locally:

```bash
make install
make serve
```
